## 1. Что за проект

`Pony Archive` - настольное приложение для ведения коллекции фигурок
My Little Pony. Приложение позволяет пользователю регистрироваться и входить
в аккаунт, добавлять фигурки с изображениями и просматривать коллекцию в виде
карточек.

Проект написан на Python. Для создания графического интерфейса используется
PySide6, для хранения данных — SQLite, для работы с паролями - bcrypt.

## 4. Чего не хватает

Вопросы, на которые не удалось найти ответа в существующем README:

1. **Как установить приложение с нуля.** Указана только команда
   `pip install PySide6`. Не описано, какая версия Python требуется,
   нужно ли устанавливать другие зависимости и рекомендуется ли использовать
   виртуальное окружение.

2. **Как запустить приложение.** Указана команда `python main.py`, но не
   объясняется, из какой директории её нужно выполнять и что делать,
   если приложение не запускается.

3. **Как пользоваться приложением.** Нет пошаговой инструкции по регистрации,
   входу в аккаунт, добавлению фигурок и просмотру коллекции.

4. **Как устроено хранение данных.** Указано, что используется SQLite,
   но не объясняется, где создаётся база данных, какие данные в ней хранятся
   и сохраняется ли коллекция между запусками.

5. **Как работать с изображениями.** Не описано, какие форматы изображений
   поддерживаются, как добавлять изображения и где они хранятся.

6. **Безопасность аккаунтов.** Указано использование bcrypt, но не объясняется,
   какие данные защищаются и как работает регистрация и авторизация.

7. **Структура проекта.** Нет описания основных файлов и модулей, поэтому
   разработчику сложно быстро понять, где находится логика интерфейса,
   работы с базой данных и авторизации.

8. **Полный список зависимостей.** В README указан только PySide6,
   хотя в проекте также используется SQLite и bcrypt. Неясно, требуется ли
   устанавливать дополнительные библиотеки.
