# Pony Archive

**Pony Archive** — десктопное приложение для хранения и управления личной коллекцией фигурок **My Little Pony**.

Приложение позволяет создавать аккаунты, добавлять фигурки с фотографиями и заметками, а также удобно просматривать и искать коллекцию.

Работает локально и не требует подключения к интернету.

## Возможности

* Регистрация и авторизация пользователей
* Хэширование паролей с помощью `bcrypt`
* Добавление фигурок с фотографиями и заметками
* Хранение данных в `SQLite`
* Просмотр коллекции в виде карточек
* Поиск и фильтрация фигурок по типу
* Работа с коллекцией без подключения к интернету

## Технологии

* **Python 3.9+**
* **PySide6** — графический интерфейс
* **SQLite** — база данных
* **bcrypt** — хэширование паролей
* **SQL** — работа со структурой базы данных

## Установка

### 1. Клонирование репозитория

```bash
[git clone https://github.com/example/PonyArchive.git
cd PonyArchive](https://github.com/Dsawari/PonyArchive.git)
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

### 3. Активация виртуального окружения

**Windows:**

```text
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Создание базы данных

```bash
python database/database.py
```

### 6. Запуск приложения

```bash
python main.py
```

## Использование

### Регистрация и авторизация

При первом запуске пользователь может создать новый аккаунт. После регистрации необходимо войти в приложение.

### Работа с коллекцией

После авторизации пользователь получает доступ к своей коллекции.

В разделе добавления фигурки можно указать её данные, загрузить фотографию и добавить заметку.

Сохранённые фигурки отображаются в виде карточек. Для быстрого поиска доступны поиск и фильтрация по типу.
